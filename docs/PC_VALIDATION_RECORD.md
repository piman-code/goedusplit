# 1.0.6 실제 PC 검증 기록 양식

이 파일은 **빈 기록 양식**입니다. 복사해서 실제 실행 결과를 적습니다. 안내가 존재하거나 자동 검사에 통과했다는 이유로 아래 항목을 통과로 바꾸지 않습니다.

검사 방법은 [실기 체크리스트](../distribution/MANUAL_QA_CHECKLIST.md), 입력과 수기 기대값은 [합성 자료 안내](SYNTHETIC_VALIDATION.md)를 따릅니다. 입력은 합성 자료만 사용합니다. 학교 파일·실제 학생 이름·학번·개인 설정·원자료 화면을 기록하거나 첨부할 필요가 없습니다.

`통과 / 실패 / 미실행 / 확인 대기` 중 실제 상태를 적습니다. 한 항목에 여러 동작이 있으면 수행하지 않은 동작도 남깁니다. 입력 기대값과 실제 값을 함께 적고, 오류는 학생정보를 제외한 설명으로 기록합니다.

| ID | 상태 | 기대값과 실제 값·실행한 동작 | 로컬 증거 파일·남은 일 |
| --- | --- | --- | --- |
| T01 분석 | 미실행 | 지필 평균46.875·수행60/40 평균45.625·학생4·문항3·선택 문항별50%; 잘못된 파일 뒤 기존 분석 유지 | 미기록 |
| T02 계산 | 미실행 | 계획서의 고정 1/3점 예와 4점 소수 예를 원점수·환산·NEIS 반올림별로 대조 | 미기록 |
| T03 저장·이동 | 미실행 | 아래 실제 Mac→Windows→Mac 왕복 기록 | 미기록 |
| T04 내보내기 | 미실행 | CSV4·근거 XLSX·NEIS XLSX·보정 XLSX 생성/값/취소; Windows Excel 실제 열기; 수식 모양 이름이 문자 | 미기록 |
| T05 개인정보 | 미실행 | 가명 기본·실명 선택 후 거절/승인·격리 snapshot 직접 식별자 제외 | 미기록 |
| T06 시험지 | 미실행 | HWPX/PDF 선택1번37.5·선택2번37.5·서답1번25; HWP 성공/부재·읽기 실패·누락 배점 결과 | 미기록 |

| T09 후보·복귀 | 미실행 | 같은 SHA 양쪽 후보/CI/필수 파일/지문·실제 설치·이전 버전과 원본 작업 복귀 | 미기록 |

소스 앱 검사, frozen 합성 QA, 사람이 사용하는 후보 검사, Windows Excel 확인은 서로 다른 증거입니다. 이번 PC에서 실행하지 않은 범위는 다른 검사 결과로 채우지 않습니다.

## T03 실제 JSON 왕복

1. Mac 후보에서 합성 계산기 작업을 열고 `T03-Mac-first.json`으로 저장합니다.
2. 승인된 방식으로 합성 JSON만 Windows에 옮깁니다. 같은 SHA 후보에서 열고 `T03-Windows-saved.json`으로 저장합니다.
3. Windows 저장 파일을 Mac으로 되가져와 같은 SHA 후보에서 열고 `T03-Mac-final.json`으로 저장합니다.
4. 문항 수·번호·유형·배점·목표·검토안·활성 검토안·직접 %·기준표를 원본과 대조합니다. 0/100/63.25%와 소수 배점을 각각 확인합니다. 파일 생성 시각 차이를 업무 값 손실과 혼동하지 않습니다.

| 실제 단계 | 후보 SHA·버전 | 파일명·SHA256 | 업무 값 대조 결과 |
| --- | --- | --- | --- |
| Mac 첫 저장 | 미확인 | 미기록 | 미실행 |
| Windows 불러오기·재저장 | 미확인 | 미기록 | 미실행 |
| Mac 재열기·최종 저장 | 미확인 | 미기록 | 미실행 |

독립적으로 새 키트를 만드는 것만으로 파일 왕복이 완료되지는 않습니다. 실제로 옮긴 파일을 검사해야 합니다.

## T08 교사 확인

교사가 합성 작업으로 `예상정답률 설계 → 표 저장 → 시험 후 분석 → 예측–실측 비교`를 직접 완료한 뒤 아래를 적습니다. 교사 실명은 필요하지 않습니다.

| 확인할 내용 | 실제 답변 |
| --- | --- |
| 핵심 흐름을 도움 없이 완료했는가? 어려웠던 조작은? | 확인 대기 |
| 경계 학생이 부족한 결과, 서답형 묶음, 참고용 기준 제안의 의미를 이해했는가? | 확인 대기 |
| 수치를 교사가 검토하고 확정하는 흐름이 실제 업무에 유용한가? | 확인 대기 |
| 배포 전에 고쳐야 할 문제와 허용 가능한 제약은? | 확인 대기 |

작은 화면에서 그래프나 표가 좁으면 기존 **요약·표 읽는 법·학생별 결과 표**를 접어 그래프를 넓히거나 **점수 분포 그래프**를 접어 표를 넓혀 확인합니다. 실제 PC의 배율에서도 축·버튼·학생 행에 접근할 수 있는지 기록합니다.

## T09 설치·복귀

설치/기존 앱 교체가 승인된 이후에만 실행합니다. [후보·복귀 안내](RELEASE_CANDIDATES.md)의 백업·원본 보존 절차를 먼저 확인합니다.

| 확인할 내용 | 실제 결과 |
| --- | --- |
| 이전 정상 버전과 원본 작업 사본을 보존했는가? | 미실행 |
| 후보 설치 후 같은 버전·SHA의 앱이 실행되는가? | 미실행 |
| 후보 종료 후 보존한 이전 버전이 실행되는가? | 미실행 |
| 이전 버전에서 원본 JSON 사본이 정상적으로 열리는가? | 미실행 |
| 설정·해시 키·기존 사용자 데이터가 보존됐는가? | 미실행 |

학교 보안 정책이 실행을 막으면 OS·안내 문구·파일 지문 대조 결과만 기록합니다. 시스템 보안 기능을 임의로 끄지 않습니다. 실제 설치/복귀를 하지 않았다면 portable 실행이나 DMG 무결성만으로 통과로 표시하지 않습니다.

## 최종 판정

현재 양식의 판정: **미실행**. 모든 필수 항목의 실제 결과와 양쪽 PC 증거를 확보한 뒤 별도로 판정합니다. 실패·확인 대기·미검증이 남으면 담당과 다음 행동을 기록하며 전체 Goal을 완료로 표시하지 않습니다.
