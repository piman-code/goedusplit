# 후보 설치 전 백업과 이전 버전 복귀

이 문서는 실행 절차입니다. **실제 사용자 데이터 백업·설치 교체·복귀를 실행한 기록은 아닙니다.** 후보 설치/기존 앱 교체와 설정 복원은 승인된 때에만 합니다. 두 PC의 실제 결과는 [PC 검증 기록](PC_VALIDATION_RECORD.md)의 T09에 남깁니다.

## 무엇을 보존하는가

| 대상 | 보존할 내용 |
| --- | --- |
| 기존 앱 | 정상 동작한 1.0.5 앱·이전 설치 파일·파일 지문 |
| 작업 | 시험 전 저장한 JSON 원본 사본. 후보의 저장 대상은 별도 이름 |
| 포트폴리오 | `subject_snapshots`를 포함한 기존 앱 저장 폴더 |
| 설정 | 창/입력 설정과 `privacy/portfolio_hash_key`가 들어 있는 앱 설정 |

해시 키와 snapshot은 함께 보존합니다. 키가 달라지면 기존 학생 해시와 새 분석 학생의 연결이 달라질 수 있습니다. 백업은 본인만 접근하는 로컬 폴더에 두며 GitHub·CI·공용 기록에 넣지 않습니다. 에이전트가 실제 자료 내용을 열어 확인할 필요는 없습니다.

## Mac에서 백업

1. Goedu-Split과 개발 소스 앱을 모두 종료합니다. 파일을 저장해야 한다면 먼저 원본을 보존하고 다른 이름을 씁니다.
2. 새 이름의 로컬 백업 폴더를 만듭니다. 같은 이름의 기존 백업은 덮어쓰지 않습니다.
3. Finder에서 기존 앱과 원본 JSON을 백업 폴더로 **복사**합니다. 기존 위치의 파일을 이동/삭제하지 않습니다.
4. `~/Library/Application Support/Goedu-Split` 폴더를 백업 폴더로 복사합니다. 정상 기본 저장 위치이며 `subject_snapshots`가 포함됩니다.
5. `~/Library/Preferences/com.goedusplit.Goedu-Split.plist`가 존재하면 같은 백업 폴더에 복사합니다. 2026-10-02 기존 PySide6에서 `QSettings("GoeduSplit", "Goedu-Split").fileName()`의 경로 메타데이터를 확인했습니다. 설정 값·해시 키·학생 데이터는 읽지 않았습니다.
6. 앱/JSON/저장 폴더/설정 파일이 각각 복사됐는지 파일명과 존재 여부로 확인하고 기록합니다. 없는 항목과 복사 실패를 구분합니다. 없는 설정을 새로 만들어 백업했다고 표시하지 않습니다.

설정 저장은 지연될 수 있으므로 앱이 실행 중일 때 복사하지 않습니다. 기본 저장 폴더에 쓰지 못하면 코드가 OS 임시 폴더의 `Goedu-Split`로 대체할 수 있습니다. 기존 저장 결과가 기본 폴더에 없다면 이전에 기록한 실제 저장 위치를 확인하며, 위치를 알아내려고 실제 학생 분석을 다시 저장하지 않습니다.

## 학교 Windows에서 백업

1. 앱과 개발 소스 앱을 종료하고 새 로컬 백업 폴더를 만듭니다.
2. 기존 설치 파일/portable 폴더 전체와 원본 JSON을 **복사**합니다. portable은 EXE 하나만 보존하지 않습니다.
3. 파일 탐색기에서 `%APPDATA%\Goedu-Split` 폴더를 백업 폴더로 복사합니다. `subject_snapshots`를 포함합니다. 임시 폴더 대체 경로를 사용했다면 기존 실제 저장 위치도 확인합니다.
4. 앱은 `QSettings("GoeduSplit", "Goedu-Split")` NativeFormat을 사용합니다. Qt의 Windows 사용자 설정 매핑에서 대응하는 앱 키는 `HKCU\Software\GoeduSplit\Goedu-Split`입니다. 이 PC의 키 존재와 내보내기는 실제 확인 대기입니다. [Qt 설정 위치 문서](https://doc.qt.io/qt-6/qsettings.html#locations-where-application-settings-are-stored).
5. 백업 폴더에서 아래 명령으로 **해당 앱 키만** 새 `.reg` 파일에 내보냅니다. 같은 이름의 파일이 있으면 먼저 다른 이름을 선택합니다. 성공 시 종료 코드0, 실패 시1이며 실패를 백업 완료로 적지 않습니다. 덮어쓰기 옵션 `/y`는 쓰지 않습니다. [Microsoft reg export 문서](https://learn.microsoft.com/en-us/windows-server/administration/windows-commands/reg-export).

```powershell
reg export "HKCU\Software\GoeduSplit\Goedu-Split" "Goedu-Split-settings-before-1.0.6.reg"
$LASTEXITCODE
```

키가 없는 새 PC라면 `기존 앱 설정 없음`으로 기록합니다. 접근 거부 등 다른 실패를 키 없음으로 처리하지 않습니다. `.reg`에는 해시 키 등 설정 값이 들어갈 수 있으므로 파일 내용은 공용 기록에 붙이지 않습니다. 이 문서 작성 중 레지스트리 내보내기·설정 변경·학교 데이터 복사는 실행하지 않았습니다.

## 후보 검증 후 복귀

1. 후보를 종료합니다. 후보에서 만든 파일은 별도 이름 그대로 보존합니다.
2. 설치 교체를 하지 않았다면 보존한 기존 1.0.5 앱/portable 폴더를 실행합니다. 기존 JSON **사본**을 열어 문항·배점·검토안을 확인합니다.
3. 설치 교체를 했다면 승인된 복귀 범위에서 이전 설치 파일/앱으로 되돌립니다. 기존 사용자 저장 폴더나 설정을 삭제하지 않습니다.
4. 앱만 되돌렸는데 기존 데이터가 보존돼 있으면 설정을 임의로 덮어쓰지 않습니다. 설정/저장 폴더 복원이 실제로 필요한 경우 현재 상태를 추가 백업하고, 복원 대상·파일·설정 키를 제시해 승인받습니다. `.reg` 가져오기나 plist 덮어쓰기는 기존 상태를 바꾸므로 이 문서만으로 자동 실행하지 않습니다.
5. 원본 JSON 사본이 정상적으로 열리는지, 포트폴리오의 기존 연결과 설정이 보존됐는지 실제 PC에서 확인합니다. Mac과 학교 Windows 결과를 각각 기록합니다.

안내가 있다는 것, 백업 파일이 있다는 것, 이전 앱이 실행됐다는 것은 서로 다른 증거입니다. 실제 원본 작업과 기존 연결까지 확인해야 T09 복귀 결과로 판단합니다. 현재 양쪽 실제 설치·복귀 결과는 미검증입니다.
