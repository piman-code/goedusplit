# 1.0.6 실제 PC 검증표

이 문서는 **실행 안내**다. 체크가 없는 항목은 미검증이다. 기존 안내는 [이력](history/MANUAL_QA_CHECKLIST-before-20261002.md)에 보존했다. AI·온라인 검토 설치와 연결은 하지 않는다.

## 시작 전에

동일 source SHA의 Mac·Windows 후보와 SHA256SUMS를 먼저 준비한다. 날짜, OS·CPU, 화면 크기·배율·밝기, 후보 파일명·SHA256, BUILD source SHA를 적는다. 기존 앱·원자료·JSON·설정을 로컬 백업한다. 학생자료는 쓰지 않고 기대값이 있는 합성 자료를 사용한다. 후보 설치/기존 설치 교체는 승인된 범위에서만 실행한다. 새 clone 개발 실행도 별도 확인한다.

## 결과를 남기는 방법

항목별 `통과 / 실패 / 확인 대기`와 실제 동작·기대값·비식별 오류 설명을 적는다. 자동 테스트나 CI 성공을 실제 PC 통과로 바꾸지 않는다. 실패한 후보는 보존하고 수정된 새 후보로 관련 항목을 다시 확인한다. T03/T08/T09의 양쪽 후보 SHA가 바뀌면 새 후보로 확인해야 한다.

Windows는 portable ZIP 전체를 새 폴더에 풀어 `Goedu-Split.exe`를 실행한다. setup 설치 검증도 필수이지만 승인된 때 별도로 진행한다. Mac은 기존 Applications 앱을 교체하지 않고 후보 경로/별도 사용자에서 검증을 시작한다. 학교 보안 안내가 실행을 막으면 OS·안내 문구·출처 확인 결과만 보고하고 보안 기능을 임의로 끄지 않는다.
