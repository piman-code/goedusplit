# Goedu-Split 1.0.3 사용설명서

성취평가 결과 분석과 문항별 예상정답률 설계를 돕는 로컬 데스크톱 프로그램입니다.
제작자: 이준서. 이 문서는 개발 버전 1.0.3 기준이며 공개 배포 완료를 뜻하지 않습니다.

## 1. 시작하기

Windows에서는 배포 ZIP 전체를 새 폴더에 압축 해제한 뒤 Goedu-Split.exe를 실행합니다. 실행 파일만 분리하지 마세요.
macOS에서는 해당 버전의 Goedu-Split.app을 실행합니다. 보안 경고가 나오면 제작자와 파일 출처를 확인하세요.

학생 성적자료를 분석하려면 왼쪽에서 학생답 정오표와 문항정보표를 선택하고, 분할점수를 확인한 뒤 **분석 실행**을 누릅니다.
추정분할점수 조회 파일과 수행평가 결과는 필요한 경우 추가합니다.
Data, 포트폴리오, 성취도, 문항, 답지반응, 성취기준 탭에서 결과를 확인합니다.

분할점수 설계만 할 때는 파일을 불러오지 않고 **예상정답률** 탭에서 시작할 수 있습니다.
시험지 PDF/HWP 검토, 오류 후보 탐지, 시험지 자동 반영, 로컬/클라우드 AI 연결은 후속 버전으로 미뤘습니다. AI 설치나 로그인은 필요하지 않습니다.

## 2. 문항 설계

1. **문항 추가** 또는 앱 상단 **자료** 메뉴의 **문항 구성안**으로 문항을 만듭니다.
2. 문항번호, 유형, 배점, 난이도, 목표 성취수준을 확인합니다.
3. **선택 문항** 탭에서 A~E 각 수준의 최소능력자가 맞힐 가능성을 O/X 또는 직접 %로 입력합니다.
4. 여러 검토안을 쓸 경우 **검토안·근거** 탭에서 검토안을 선택해 각각의 판단을 작성합니다.
5. 상단의 100점 환산 분할점수를 확인하고, **점수 비교**를 펼쳐 문항 수와 배점 합계를 확인합니다.

문항을 삭제하려면 **문항표**에서 삭제할 문항을 체크한 뒤 상단의 **문항 제거**를 누릅니다.
앱 상단의 **자료** 메뉴에는 **분석자료 보내기**, **문항 구성안**, **근거 엑셀**, **계산기 새로고침**이 있습니다.

O/X의 2/3은 3명 중 2명, 즉 약 66.67%를 뜻합니다. 계산에는 반올림 전 비율을 사용합니다.
직접 입력한 63.25%나 100%도 그대로 보존합니다. 목표수준 변경으로 생성되는 기본값은 교사 판단의 출발점이며 공식 강제 기준이 아닙니다.
목표수준·난이도를 바꿔 기본값을 다시 제안받은 뒤에는 A~E 값을 재검토하세요.

### 작은 화면에서 작업하기

**예상정답률** 탭에서는 창 너비가 1440px 미만이면 왼쪽 입력 패널이 자동으로 접힙니다.
직접 접은 패널은 창을 늘려도 앱을 종료하기 전까지 접힌 상태를 유지합니다. 필요하면 앱 왼쪽 상단의 **입력 패널 보이기/숨기기** 아이콘으로 엽니다.
계산기 도구막대의 **작업 불러오기**, **CSV 내보내기**, **작업 저장** 아이콘은 마우스를 올리면 이름이 표시됩니다.

1. **문항표** 탭에서 문항번호, 유형, 배점, 난이도, 목표 성취수준을 확인합니다.
2. 편집할 문항을 고르고 **선택 문항** 탭을 엽니다. 높이를 넉넉하게 쓰는 독립 편집 화면 위쪽에서 A~E 값을 입력합니다.
3. **문항표** 탭 또는 `Escape`로 표에 돌아옵니다. 다른 검토안은 **검토안·근거** 탭에서 선택하고, 기본 예상정답률을 조정하려면 **목표 설정**을 엽니다.
4. 상단에 항상 표시되는 다섯 경계의 100점 환산값을 확인합니다. 원점수와 NEIS 반올림 후 값을 함께 보려면 **점수 비교**를 펼칩니다.
5. **작업 저장** 아이콘으로 JSON 작업 파일을 보관합니다. NEIS 준비표가 필요하면 앱 상단의 **NEIS 입력표** 버튼을 누릅니다.

## 3. 분할점수 해석

원점수 기준 분할점수 = 모든 문항의 (배점 × 해당 수준 예상정답률 ÷ 100)의 합입니다.
100점 환산 분할점수 = 원점수 기준 분할점수 ÷ 전체 배점 합 × 100입니다.

예를 들어 총 40점 시험에서 B 수준 합계가 26점이면 B/C 경계는 원점수 26점, 100점 환산 65점입니다.
A/B, B/C, C/D, D/E, E/미도달의 다섯 경계는 상단에 100점 환산값으로 항상 표시됩니다.
**점수 비교**를 펼치면 원점수와 NEIS 반올림 후 값을 함께 확인할 수 있습니다.
여러 검토안이 있으면 문항별 정답률의 산술평균을 사용합니다. 현재 선택한 검토안 하나만의 결과가 아닙니다.
문항 선택 체크는 삭제 등의 작업 범위이며 전체 분할점수의 계산 범위를 바꾸지 않습니다.

화면의 소수 표시는 읽기 편하게 줄일 수 있지만 내부 계산과 저장값을 그 자리수로 자르지 않습니다.
결과는 교사의 검토·협의용 예상값이며 공식 확정값이나 결재를 대신하지 않습니다.

## 4. NEIS 입력표와 검토표 저장

1. 앱 상단의 **NEIS 입력표** 버튼을 누릅니다. 계산기의 현재 문항값을 확인합니다.
2. 문항구분과 난이도별 묶음, 문항 수, 배점 합계를 확인합니다.
3. 원래 분할점수와 NEIS 반올림 후 결과의 차이를 확인합니다.
4. 엑셀 저장 또는 필요한 형식으로 복사합니다.
5. 학교 평가계획과 실제 NEIS 화면을 대조한 뒤 입력합니다. 앱이 NEIS에 자동 전송하지는 않습니다.

묶음 정답률은 배점 가중평균을 먼저 구하고 가장 가까운 5%로 반올림합니다. A~E 모두 같은 규칙이며, 82.5%는 85%, 12.5%는 15%가 됩니다.
문항마다 미리 반올림한 뒤 평균을 내는 방식과 다를 수 있습니다.
검토표 XLSX에는 **분할점수 비교**, **문항별 입력값**, **NEIS 입력표** 시트가 들어갑니다. 원래 입력값과 반올림 결과를 함께 보관하세요.

배점은 0보다 커야 합니다. 정답률은 0~100%이며 A ≥ B ≥ C ≥ D ≥ E여야 합니다.
같은 유형의 문항번호가 중복되거나 값이 잘못된 경우 복사·내보내기를 진행하지 않습니다. 원본 입력을 수정하세요.
선택형 1번과 서답형 1번은 서로 다른 문항으로 허용됩니다.

## 5. 작업 보관과 이어하기

계산기 도구막대의 **작업 저장** 아이콘으로 JSON 작업 파일을 보관하고 **작업 불러오기** 아이콘으로 이어갑니다.
검토안별 O/X, 직접 %, 문항 배점·목표·근거를 함께 보관합니다. **CSV 내보내기**와 엑셀 검토표는 확인용 출력물이며 JSON 작업 파일의 대체물이 아닙니다.
**작업 저장**이나 **CSV 내보내기**를 누르면 저장 위치를 묻는 창이 뜹니다. 저장 대화상자를 취소하면 파일을 만들지 않습니다. 불러오기 오류가 발생하면 기존 작업을 유지하고 파일 형식을 확인합니다.
**자료** 메뉴의 **근거 엑셀**은 협의용 세부 근거를, 앱 상단 **NEIS 입력표**의 엑셀 저장은 원값과 반올림 결과 비교를 남깁니다.

## 5-1. 시험 후 예측-실측 비교

시험이 끝나 정오표가 나오면, 시험 전에 입력한 예상정답률이 실제와 얼마나 맞았는지 확인할 수 있습니다.

1. 시험 후 정오표와 문항정보표로 **분석 실행**을 합니다.
2. 시험 전에 저장한 작업 파일을 계산기의 **작업 불러오기**로 엽니다.
3. **자료** 메뉴의 **예측-실측 비교**를 누릅니다.

실측은 각 성취수준에서 점수가 낮은 1/3 학생(최소능력자에 가까운 경계 학생)의 정답률입니다. 수준 전체 평균은 표 칸에 마우스를 올리면 보입니다.
차이가 15%p 이상인 칸은 색으로 표시하고, 수준별로 예측이 평균적으로 높았는지 낮았는지 요약합니다.
서답형은 정오표에 학생별 총점만 있어 문항별이 아니라 묶음으로 비교합니다.
실제 성취수준은 이번에 적용한 분할점수로 나눈 결과이므로, 이 비교는 다음 예측을 조정하기 위한 참고 자료입니다. 학생 수가 적은 수준은 참고만 하세요.
**엑셀 저장**으로 요약과 문항별 비교를 남길 수 있으며, 학생 개인정보는 들어가지 않습니다.

## 6. 개인정보와 보안

이번 작업 화면은 AI 제공자를 호출하지 않으며 기본 분석과 분할점수 계산은 PC에서 수행합니다.
로컬 저장이 파일 암호화나 접근 통제를 의미하지는 않습니다. 작업 파일·성적 내보내기는 학교 보안 기준에 맞는 위치에 보관하세요.
동기화 폴더에 저장하면 해당 서비스가 파일을 업로드할 수 있으므로 저장 위치를 확인하세요.
공유 전에는 학생 이름, 반/번호, 성적 등 불필요한 개인정보가 없는지 확인하세요.

결과 CSV와 **근거 엑셀**은 기본적으로 학번·반/번호·이름 대신 가명(학생 001, 학생 002…)으로 저장합니다. 예상정답률 계산기에 보내는 분석자료와 계산기 작업 파일도 가명을 씁니다. 실명이 필요하면 저장 창의 **실명 포함** 확인란을 켜고 경고를 확인한 뒤에만 저장됩니다.
가명 번호는 분석할 때마다 명부 순서와 무관하게 섞어 매기고, 파일의 행도 가명 순서로 저장합니다.
가명은 익명이 아닙니다. 학급·점수로 명부를 가진 사람은 학생을 알아볼 수 있으니 가명 파일도 성적 자료로 관리하세요.
가명과 실제 학생은 **예상정답률** 탭 **자료** 메뉴의 **가명 ↔ 실명 확인**에서 화면으로만 확인할 수 있습니다. 파일로 저장되지 않습니다.
학생 포트폴리오 스냅샷에는 학번·반/번호·이름 대신 이 PC의 앱 설정에 둔 비밀 키로 만든 학번 해시만 저장합니다. 포트폴리오 화면의 이름은 지금 불러온 분석 자료에서 찾아 보여 주며, 찾지 못하면 `학생#abc123`처럼 표시합니다.
앱 설정을 초기화하거나 다른 PC로 옮기면 비밀 키가 달라져 이전 스냅샷과 새 스냅샷이 같은 학생으로 연결되지 않습니다. 예전 버전에서 저장한 스냅샷도 계속 읽지만, 그 파일 안에는 실명이 남아 있습니다.

## 7. 자주 묻는 질문

**문항 오류를 자동으로 찾아주나요?** 이번 버전에서는 제공하지 않습니다.

**목표수준을 정하면 자동값을 그대로 쓰면 되나요?** 아닙니다. 최소능력자 특성, 성취기준, 실제 문항을 근거로 교사가 확인해야 합니다.

**NEIS 표와 상단 점수가 왜 다른가요?** 묶음별 5% 반올림 때문일 수 있습니다. **점수 비교**를 펼쳐 원점수와 100점 환산값, NEIS 반올림 후 값을 함께 확인하세요.

**숫자가 역전되었다는 오류가 나옵니다.** 해당 문항의 A~E 직접 입력값과 각 검토안의 O/X를 확인하고 수정하세요.

**분석자료가 없어도 되나요?** 예상정답률과 NEIS 준비표 작성에는 필요하지 않습니다. 실제 학생 성취도 분석에는 정오표와 문항정보표가 필요합니다.
